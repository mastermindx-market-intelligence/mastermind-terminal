# Precise date readout at enlarged text

The native date editor can horizontally clip its year or milliseconds at 200% text enlargement on a 390px viewport. The associated wrapping readout presents the exact local draft value without changing the editor, timestamp conversion, millisecond step, or explicit Save behavior.

The nine accepted cases cover real Firefox 151 text-only enlargement (textZoom2, fullZoom1) in English at 390/820/1440, and standard Chromium in English/Chinese at the same widths. Original, edited-unsaved and exact-reopened PNGs and raw owner/geometry/runtime receipts are retained for each case. The original failing mobile image remains separate.

This is local isolated fixture browser evidence. It does not prove Chinese Firefox text-only rendering, full-page accessibility, live principal behavior, installation or production delivery. The native input may still scroll internally; the associated readout provides the complete value.

The external original harness and red/green logs are bound by the source/browser acceptance receipt. Existing original capture recipes, evidence tests and before images were unchanged.
