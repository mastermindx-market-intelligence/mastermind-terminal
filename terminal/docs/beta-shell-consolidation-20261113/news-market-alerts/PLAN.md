# News Intelligence and Market Alerts · shared-shell design

Chairman assignment, 14 November 2026. Extend the [beta-shell consolidation](https://github.com/mastermindx-market-intelligence/mastermind-terminal/blob/b80e58a2b254ed49eb9e573c1131cf09e13e18af/terminal/docs/beta-shell-consolidation-20261113/PLAN.md) with two native market desks. The current phase is Paper design. Implementation follows verified editable canvases. This branch is scoped to design sources and build notes.

## Outcome

An investor can open a ranked story, identify a corrected claim, inspect the original sources and return to the same place. The same shell admits a market-alert desk where the investor can distinguish a new actionable observation from an older important firing, inspect the original evidence and return from the relevant source panel. Both journeys must work by keyboard and phone, and convey partial coverage, stale snapshots, rights and access honestly.
