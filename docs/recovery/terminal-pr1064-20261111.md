## Concrete repairs

1. Vertical wheel input zooms time; horizontal input pans. Each option gates its own
   axis, diagonal input can apply both, and browser event consumption follows the same
   rules. Disabled vertical chart gestures no longer silently become horizontal pans.
2. Public crosshair events identify the actual pane after reordering and expose
   pane-relative Y. Internal gesture distances and overlay painting retain chart Y.
3. Price-scale `options()` retains configured border/text presentation options while
   resolving live pane scale state and returning independent margin values.
4. A visible logical range that does not require clamping retains its exact fractional
   endpoint; repeated no-op writes do not introduce floating-point drift or events.
5. A selected left price axis now paints on the left, including border, ticks, labels,
   primitives, crosshair and time-label placement. Native input subtracts the plot
   offset once. Public time/series coordinates stay local to the plot, and snapshots
   still compose whole pane bitmaps without adding another offset.
6. Absolute price-axis wheel/press anchors use the local Y of the hit pane. Pointer
   deltas and cross-pane pinch distances retain chart-relative coordinates.
7. Large Trades, marker tooltips, lazy suite allocation and phone maximize tests read
   each renderer's actual pane/plot geometry. The native canvas publishes the bounds
   of its completed paint, including the axis strip. The shared reader rejects stale
   bitmap dimensions, preserves topology/fill checks and native hit ownership, and
   does not force a paint. Maximize touch targeting retains visible-pane indexing.
