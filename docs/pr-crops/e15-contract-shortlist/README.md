# E15 — exact-contract shortlist and comparison crops

Generated by the opt-in block in `terminal/e2e/options-contract-shortlist.spec.ts`:

```sh
cd terminal
TERMINAL_CROPS=1 TERMINAL_E2E_PORT=<port> npx playwright test e2e/options-contract-shortlist.spec.ts \
  --workers=1 --project=desktop --project=tablet --project=mobile -g "PR crops"
```

The page is `/options?tab=screener` in the product's dark theme. The Open-interest builds and
Hot contracts payloads are intercepted with the spec's fixture rows. Those rows include an
adjusted root (`NVDA1`) at the same strike as `NVDA`, a row with a null midpoint (`SPY 530 P`),
and a Hot list from a later session served as an older cached copy (`stale: true`). The script
pins `NVDA`, `NVDA1` and `SPY` from Open-interest builds and `NVDA` again from Hot contracts,
then opens the comparison.

Each crop exists for desktop 1440×900, tablet 820×1180 and mobile 390×844, in EN and ZH.

| file | what it shows |
|---|---|
| `<vp>-<lang>-dark-viewport.png` | What the user sees at that viewport, scrolled to the top of the shortlist. |
| `<vp>-<lang>-dark-compare.png` | The whole shortlist and comparison, taken at the same width in a 2400px-tall window. At desktop and tablet the results region is an inner scroller that would cut the crop at its fold. |
| `<vp>-<lang>-dark-pinned-rows.png` | The originating Open-interest builds table after pinning. Three rows are pressed and the population and order are unchanged. |

What to check in the comparison:

- The executable bid/ask, spread and size rows read "Not supplied: no live quote in this source" in every column. The midpoint is labelled as an end-of-day reference mark, not as an executable quote.
- Multiplier, deliverable, settlement and exercise style read "Not supplied, not assumed standard".
- `NVDA` and `NVDA1` stay separate columns. `NVDA1` carries the adjusted-root note.
- The missing `SPY` midpoint stays blank ("Missing in this row") and is not filled from another column.
- The banner names the session mismatch (2026-07-04 vs 2026-07-05), the different source lists and the older cached copy, so the columns are not presented as like-for-like.
