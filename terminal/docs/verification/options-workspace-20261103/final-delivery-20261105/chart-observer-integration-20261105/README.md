# Independent branch proof binding

The final source composition check exposed a real evidence-reader defect when Options was combined with protected master without the Exposure companion. That valid tree uses the captured integrated chart source with the original Options browser test file. The reader unnecessarily tied those two independently composable identities together.

The two actual captured browser test files have identical chart observations and assertions. Their entire difference is two comments and a 30-second readiness budget on an unrelated return assertion. A regression verifies that exact whole-file difference against both archived SHA-bound test files.

## Red and green proof

The non-Git preview was temporarily projected to all tracked application/test files and native root manifests of the actual Options-only tree, with the candidate reader/regression edits explicit. The original reader caused both GEX/EOD suites to fail collection with `CHART_FRAMING_CURRENT_OBSERVER`, and both cross-profile regressions failed. With only the reader corrected, all **39/39** selected tests passed. The projected source maps differ only in the reader. Exposure combined with protected master alone also passed **50/50** native evidence and observer tests. The complete combined preview was restored after each run.

The corrected reader first validates the baseline and both six-case captures, their exact historical source/observer bindings, pinned files, every geometry attachment, primary label and reset repaint. It then accepts either current observer already recorded by those proofs. Unknown observers and altered bound files still fail. No third observer or new raw source hash is admitted.

The final affected suites passed **120/120** original Options, **112/112** Exposure and **284/284** current integration tests. The combined full TypeScript check and changed-source lint also passed. The latest protected Python producer's previously verified **59/59** tests remain unchanged.

The new tests cover all four recognized chart/observer combinations, the exact observer difference, unknown-observer rejection on both chart identities and bound-file corruption. The first regression authoring attempt used a non-unique line as its exact-diff anchor; that failed attempt is retained, and the unchanged neighboring comment supplies a unique anchor in the final test.

The application runtime and all browser/capture inputs remain unchanged. Existing 294 state captures, 78 broader journeys and 12 final chart journeys retain their original evidence scope.
