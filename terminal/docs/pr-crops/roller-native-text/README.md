# Mobile roller native text enlargement

The selected symbol was clipped at real Firefox text-only 200%: NVDA's 99.8px text occupied an 83.4px wheel, and its glyph height exceeded the fixed 23px row. The original geometry test failed after its normal-size positive control passed.

The component now measures an intrinsic inline text box, observes font/layout changes, and uses the same measured pitch for rendering, live drag detents, centre taps and projected flicks. Scoped CSS lets the row fit its text. Normal NVDA/W geometry remains 83.4/54px with 23px pitch in the unchanged 46px strip; enlargement gives a 106px symbol chamber and 46px row. Action buttons remain 44px.

Validation: 5 mounted tests cover resize/restore, live enlarged detents, flick projection, keyboard selection, and observer replacement after empty lists. Three real Firefox native cases cover 320/390px geometry, keyboard and clipping negative controls, plus a real mouse drag committing W→3D while held and native text reset restoring normal geometry. Seven existing mobile browser cases pass for normal geometry, rolling, 320/360/390/430px action targets and focus; two existing desktop/tablet absence cases pass. All run once on the final source with one worker/no retries, except the native geometry case whose initial incorrect one-Tab-to-Draw expectation was corrected to follow Firefox's actual scroll-container focus stop. TypeScript and focused lint pass. Screenshot files are original full-viewport images, reviewed directly.

The original Fabric proposal was consumed but NOT_ACCEPTED: its patch targeted nonexistent module rules and used invalid `max(px, max-content)` width syntax. The parent corrected and validated the delivered artifact; this is not independent review or acceptance of the raw worker patch. The initial candidate's geometry and arrow assertions passed before the Tab harness failure; that failure and the original product RED are retained externally.

Scope: English native text200 with local fixtures, exact retained owners and zero owner/auth writes or model commands. Expected Terminal chart-state mirrors were intercepted locally. These screenshots also show unrelated header/chart/Research Desk enlargement defects; they do not establish whole-page accessibility, Chinese native-text support, larger zoom levels or production acceptance. The old 403-image corpus, original recipes and before images are reused unchanged. No global stylesheet, schema, owner API or release gate changed.
