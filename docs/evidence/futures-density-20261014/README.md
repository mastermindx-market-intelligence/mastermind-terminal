# Dense gamma visualization: observed defect and repair

A synthetic but valid 203-strike, 24-frame source produced 4,872 SVG circles even
though only three strikes were in the visible price range. The previous fixed
400-million scale also rendered 800M, 1.6B and 3.2B exposures at the same maximum
radius. An executable browser falsifier reproduced the DOM problem on the old
renderer (the first test-server startup had timed out before execution; the normal
configuration then ran with diagnostic logging and exposed the actual defect).

The display now culls only offscreen SVG circles, not source rows. Its explicit
1/2/5 visible-price/time scale uses admitted frames only, never later replay data.
A bilingual legend discloses the scale and its range dependence. Source amounts,
source receipts, mapped coordinates and the 203-row inspector remain unchanged.
Signed M/B labels fit the price gutter. The actual-price historical sample still
has no invented gamma.

All three viewports pass: 72 circles, all 203 source rows retained, 800M < 1.6B <
3.2B visual radii, and visible $5B scale. This is about 98.5% fewer gamma-circle DOM
nodes IN THIS TEST, not a production latency/capacity or total-frame-time claim.
Four pure scale/null/zero/causality/format controls pass; 272 focused domain/API/
existing-level checks passed before the final label-format-only adjustment.
The immutable original domain review remains separately pending and does not
silently approve this subsequent display delta. Full responsive/regression build
qualification and source activation remain separate obligations.
