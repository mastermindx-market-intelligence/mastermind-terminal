## Product decisions

1. Reuse the normal Terminal chart and its existing OptionsRail/OptionsCompanion. Keep options lazy and optional; no separate chart shell, mobile product, token root, data cache or workspace store.
2. Organise the workflow around Discover → Inspect → Understand → Plan → Watch → Review. Retain dense expert tools in deliberate destinations, with common controls visible and advanced controls disclosed.
3. Preserve exact identities: underlying/listing, option root, expiry, strike, right, source vintage, live/replay clock and scenario assumptions are different facts. Never silently substitute a neighbouring expiry, symbol or observation.
4. Reuse D08B/C/D designs, build contracts and retained semantics. Select original layouts that fit current Terminal primitives; preserve analytical depth and accessible return paths rather than stacking every historical mockup.
5. Use Skylit as public workflow evidence: contextual modules, persistent workspace context, chart overlays and investigation continuity. Implement original presentation and reuse our actual data/calculation owners. Free-account access cannot establish paid-feature absence.
6. Keep observed flow, inferred execution side, dealer assumptions, hypothetical plans, simulated positions and actual holdings visibly distinct. Do not invent trade authority, forecasts, scores or unavailable measurements.
