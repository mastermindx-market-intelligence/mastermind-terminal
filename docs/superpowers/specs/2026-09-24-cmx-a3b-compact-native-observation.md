## Selected design and alternatives
Project A3's in-process successful result deterministically. Do not accept a caller-authored snapshot as a new network/file ingress. Reuse A3 computation, input refusal, settings, event-time helper output, native metadata, and canonical JSON fingerprints. Alternative LLM summarization would add cost and unverifiable numerical translation; alternative indicator reimplementation would create parity drift. Neither is selected.

One compact packet carries original source/input/settings/result identity, a whole-snapshot SHA256 (content identity, not authentication), unchanged basis limitations, module switch/lock visibility, and four bounded fact groups:
- series: two latest actual samples of native poly/gradline/columns primitives, with bar indices, source pointers, ages and null gaps. Do not carry an older finite value forward over a null or an absent final-bar sample.
- events: newest confirmations, not newest anchors or array tail. Preserve native type/direction/label/value/strength and existing source-bar timing; strength is not probability and p is not automatically a price.
- geometry: right-extended native lines/zones, using original coordinates. Do not relabel them support/resistance or attach fabricated knowability.
- tables: native displayed row text with original column metadata and table footnote. Never parse display prose into calibrated numerics or drop a resampling-basis footnote.

Every fact links by JSON pointer to the exact A3 snapshot. Selection is deterministic presentation, not opportunity ranking. Preserve unknown warmup/module health, caller-asserted data revision/finality, missing knowledge-time, renderer caps, native coordinate units, and no predictive/signal authority. Empty, disabled or locked results never become no-setup judgments. Text is source data, not instructions or executable markup.

## Bounds and compatibility
At most 12 KiB of actual UTF-8 JSON, plus one CLI newline; max 6 series, 8 events, 4 geometry objects, 4 table rows. Round-robin category admission avoids a large group starving all other groups. Omit whole facts, never cut numbers/text or silently drop categories; counts report total/eligible/invalid/returned/omitted and omitted bundle categories. Oversized essential identity/basis refuses. Inherit A3's 256 KiB full-bundle ceiling; compact mode does not bypass an upstream refusal.
Existing CLI default full mode and --tier behavior stay intact. Add --view full|compact, reject duplicate/unknown flags. Tier is trusted operator context, absent from request JSON; no production/customer entitlement claim. No backend, BrainWidget, chart bus, native kernel/host, provider, data, alert, evaluator, queue or permission-owner edits.
